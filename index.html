Your agents remember.让你的 AI agent 记得住。

nestwork is a git-native memory protocol for AI coding agents — persistent memory and shared context that live in your own private git repo. No server, no plugin, no vendor lock-in.nestwork 是面向 AI 编码 agent 的 git 原生记忆协议——持久记忆与共享上下文，全部存在你自己的私有 git 仓库里。不需要服务器，不需要插件，不绑定任何厂商。

Protocol 2.4 v0.6.0 Claude · Codex · Gemini · Hermes · OpenClaw
Use this template用模板创建我的仓库 View on GitHub查看 GitHub 仓库

Every new session, your agent starts from zero每开一个新会话，你的 agent 都从零开始

The agent on your work machine knows your rules. The one on your laptop starts blank.

公司电脑上的 agent 知道你的规矩，个人电脑上的那个一片空白。

A cloud dev box cannot see the progress you recorded somewhere else.

云端开发机看不到你在别的机器上记录的项目进度。

Switching sessions or tools means re-explaining who you are and what was decided.

切会话、换工具，就得重新解释一遍你是谁、之前定了什么。

Vendor-private memory locks your context into one ecosystem.

厂商私有的记忆功能，把你的上下文锁死在一个生态里。

One private git repo as the shared brain一个私有 git 仓库，当所有 agent 的共享大脑

01

Create your repo

创建你的仓库

Click "Use this template" on GitHub and set it private. The memory is yours alone.

在 GitHub 上点 "Use this template"，设为 private。记忆完全属于你自己。

02

Install the hooks

装上 hook

One script per tool wires up session-start context injection and per-write auto-commit.

每个工具一行安装脚本，自动接好「会话启动注入上下文」和「每次写入自动提交」。

03

Every agent reads the same context

所有 agent 读同一份上下文

Claude, Codex, Gemini, Hermes — same versioned memory, across sessions, machines and vendors.

Claude、Codex、Gemini、Hermes——同一份带版本的记忆，跨会话、跨机器、跨厂商。

Context priority chain上下文优先级链
queen/agent-rules.md  >  queen/strategy.md  >  shared/memory.md  >  agents/*/*/memory.md  >  projects/*.md  >  workflow/*.md

What you get你会得到什么

Git-native

git 原生

Plain markdown in a git repo. No database, no daemon, no third-party service.

就是 git 仓库里的普通 markdown。没有数据库，没有常驻进程，没有第三方服务。

Cross-tool

跨工具

Works with any markdown-config agent: Claude Code, Codex CLI, Gemini CLI, Hermes, OpenClaw.

任何用 markdown 配置的 agent 都能接：Claude Code、Codex CLI、Gemini CLI、Hermes、OpenClaw。

Cross-machine

跨机器

Clone the repo on a new machine and the agent already knows your stack, rules and open threads.

在新机器上 clone 一下，agent 就已经知道你的技术栈、规矩和在飞的活。

Encrypted mode

加密模式

Optional git-crypt layer keeps private memory unreadable even to the git host.

可选的 git-crypt 层，让私有记忆连 git 托管方也读不到。

Agent mailbox

Agent 信箱

Git-native inter-agent messaging: one agent leaves a note, another picks it up at session start.

基于 git 的 agent 间通信：一个 agent 留言，另一个在会话启动时自动收到。

Memory distillation

记忆蒸馏

Private per-agent memory is merged into shared memory on demand — union, never destructive.

按需把各 agent 的私有记忆合并进共享记忆——只做并集，永不删除。

Quickstart快速开始

After creating your repo from the template, clone it and run the installer for your tool:用模板创建仓库后，clone 下来，跑对应工具的安装脚本：

macOS / Linux 
git clone https://github.com/<you>/<your-repo>.git nestwork
bash nestwork/scripts/install/claude.sh
bash nestwork/scripts/install/codex.sh
bash nestwork/scripts/install/gemini.sh
Windows PowerShell 
git clone https://github.com/<you>/<your-repo>.git nestwork
.\nestwork\scripts\install\claude.ps1
.\nestwork\scripts\install\codex.ps1
.\nestwork\scripts\install\gemini.ps1
