AI agent 记忆：文章与指南

文章20 篇更新于 2026-09-27

给 AI 编程 agent 加长期记忆的实用指南——跨会话、跨机器、跨工具。每条说法都对照过 nestwork 源码，或附上了原始出处。

指南

AI agent 记忆：四种类型与取舍AI agent 记忆是智能体在单次会话之外还能依赖的上下文。对比上下文窗口、工具内置记忆、向量检索服务和文件式记忆，以及编码 agent 的特殊需求。Claude Code 记忆跨设备同步：用 git 实现Claude Code 的 CLAUDE.md 和 auto memory 都只在本机。本文讲清它们存在哪、为什么换电脑就没了，以及怎样用 git 跨设备同步。Claude Code 和 Codex 共享记忆的做法Claude Code 读 CLAUDE.md，Codex 读 AGENTS.md。让两者指向同一个私有 git 仓库，就能共享记忆，且各写各的目录。Codex 记忆与 AGENTS.md：Codex 长期记忆Codex CLI 现有的记忆方式（AGENTS.md 与默认关闭的本地 memories），以及如何用 git 给 Codex 加跨会话、跨机器的长期记忆。agent 记忆工具对比：Mem0、Letta、Zep 等从架构、部署方式、数据归属和适用场景，对比 Mem0、Letta、Zep、Supermemory、claude-mem、工具内置记忆和 nestwork。记忆基准测试：LoCoMo、LongMemEval、BEAMLoCoMo、LongMemEval、BEAM 各测什么、LLM 裁判怎么打分、厂商分数为何不能横比，以及编码 agent 该看哪些指标。AGENTS.md 和 CLAUDE.md 区别，记忆该放哪AGENTS.md 是跨工具的指令文件，CLAUDE.md 是 Claude Code 专用的，记忆是 agent 自己写的笔记。各工具读哪个、怎么组合。上下文窗口有限，AI 记忆该怎么按需加载启动时只放一小层常驻记忆，其余经由自动生成的主题索引按需读取。实测启动从约 6.96 万 token 降到约 640 token。多 agent 共享记忆，怎样避免写冲突多个 AI agent 共用一份记忆，靠的是每个 agent 只写自己的目录、每次写入原子同步、冲突时按归属规则取舍，而不是更复杂的合并算法。用 git 管理 AI 记忆，为什么不需要服务器不用记忆服务器也能让 AI 编码 agent 拥有长期记忆，把记忆写成 markdown 放进私有 git 仓库即可。git 能解决什么、不能解决什么。记忆蒸馏，怎样合并多个 agent 的记忆记忆蒸馏把多个 agent 的私有笔记合并成一份经过审核的共享记忆。本文讲什么该进共享记忆、审核流程，以及 distill.py 怎么用。多 agent 协作怎么留言：用 git 做 agent 邮箱不同机器上的 AI agent 可以通过 git 互相留言：各写各的 outbox，按需读取发给自己的消息，不需要服务器、消息队列或机器人。AI 记忆加密：用 git-crypt 保护 agent 记忆用 git-crypt 加密放在 git 里的 AI agent 记忆：本机读写明文，托管平台只存密文。附实测步骤、主题记忆规则和局限。换电脑 AI 记忆丢失？迁移工具原生记忆Claude Code 的 auto memory 和 Codex 的 memories 都只存在本机。换电脑、换工具或丢账号之前，如何备份并迁移 AI 记忆。AI 长期记忆用起来是什么样：积累、迁移与维护给 AI agent 加上跨会话的长期记忆后，日常会怎样：上下文如何积累、换机器换工具时发生什么、记忆多了怎么办、要做哪些维护。nestwork 安装教程：给 AI agent 加长期记忆用 nestwork 给 Claude Code、Codex 加长期记忆：前置条件、安装与卸载、怎么验证生效、费用、隐私、升级和团队使用，逐条问答。
