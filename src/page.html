01 / The problem问题

Every session
starts at zero.

每个新会话，
都从零开始。

You spent an afternoon teaching one agent your stack, your rules and where the project stands. Open a new session, a second laptop or a different tool — and it is gone. You are back to reciting your own medical history.

你花一下午教会一个 agent 你的技术栈、你的规矩、项目进行到哪一步。换个会话、换台电脑、换个工具——全没了。你又得把自己的「病历」从头背一遍。

ERR_01

Machine-bound

记忆锁在一台机器上

The agent on your work computer knows your rules. The one on your laptop, your cloud box or your phone starts blank.

公司电脑上的 agent 懂你的规矩，笔记本、云服务器、手机上的那个一片空白。

ERR_02

Vendor-locked

被一家厂商锁死

Claude's memory only feeds Claude, Codex's only feeds Codex. Switch tools and the context you built stays behind.

Claude 的记忆只喂 Claude，Codex 的只喂 Codex。一换工具，辛苦攒的上下文全留在原地。

ERR_03

Agents don't talk

agent 之间互不通气

One agent records a gotcha; another agent, one machine over, walks straight into it the next day.

一个 agent 刚记下的坑，隔壁机器上的另一个 agent 第二天照样踩进去。

ERR_04

Fragile ownership

记忆不归你所有

A lapsed subscription, a regional block or a lost account can wipe out months of accumulated context overnight.

订阅到期、地区限制、账号丢失，任何一件都能让你攒了几个月的上下文一夜清零。

“On machine A an agent wrote down ‘this deploy script has a nasty gotcha’. The next day, the agent on machine B stepped on the exact same rake.”

“我明明在 A 机器上让 agent 记下了『这个部署脚本有个坑』，B 机器上的 agent 第二天又踏踏实实踩了一遍。”

02 / How it works工作原理

One repo.
One brain.

一个仓库，
一个大脑。

nestwork is not a service you run — it is a protocol your agents follow. Memory is plain markdown in your own private git repo. Every agent pulls before it reads and commits after it writes, so whatever one agent learns, every other agent can use next session.

nestwork 不是一个要你部署的服务，而是一套 agent 共同遵守的协议。记忆就是 你自己私有 git 仓库 里的普通 markdown。每个 agent 读之前先 pull、写之后立即提交，于是一个 agent 学到的东西，下一个会话里所有 agent 都能用上。

Create your private nest

创建你的私有记忆仓库

Click Use this template on GitHub and make it private. It is your repo, on your account — nothing is sent to anyone else.

在 GitHub 点 Use this template，设为 private。仓库在你自己的账号下，不经过任何第三方。

02

Run one installer per tool

每个工具跑一行安装脚本

Clone it on each machine and run the installer for Claude Code, Codex, Gemini, Kimi, Hermes or OpenClaw. It wires up session-start loading and sync hooks.

在每台机器上 clone，然后给 Claude Code、Codex、Gemini、Kimi、Hermes 或 OpenClaw 跑对应安装脚本，自动接好启动加载和同步 hook。

03

Just keep working

照常干活就行

Hooks run pull --rebase before every memory write and commit + push right after. Open any agent on any machine and it already knows you.

每次写记忆前 hook 自动 pull --rebase，写完立即 commit + push。任何机器上打开任何 agent，它都已经认识你。

your-nest/ # private git repo — the shared brain ├── queen/ # rules & strategy · human-owned, read-only for agents ├── shared/ # cross-agent memory · topic files + generated index ├── agents/ │ └── <host>/<agent-id>/ # each agent writes ONLY here → no write conflicts ├── projects/ # live project state └── workflow/ # portable methods that follow you between jobs
queen/agent-rules>queen/strategy>shared>agents/*>projects>workflow

Authority chain: when two sources disagree, the higher layer wins — agents never blend conflicting instructions.

权威链：两处说法冲突时，高层说了算——agent 不会把矛盾的指令搅在一起。

03 / Context that scales能长期积累的上下文

Loads like
a skill.

像 skill 一样
按需加载。

More context is not better context: a model's effective attention is far smaller than its advertised window. So nestwork never dumps your whole history into the prompt.

上下文不是越多越好：模型真正能用好的注意力，远小于标称的上下文窗口。所以 nestwork 从不把你的全部历史一股脑塞进提示词。

  • Resident tier, ~640 tokens. At startup an agent reads only the core rules and two short summaries — byte budgets are checked by script.
  • 常驻层，约 640 token。 启动时只读核心规则和两份简短摘要，字节预算由脚本检查。
  • Topic index. Memory is split into topic files, each with a one-line description saying when to read it. memory.md is a generated routing table.
  • 主题索引。 记忆拆成一个个主题文件，每个都带一行 description，写明什么时候该读；memory.md 是自动生成的路由表。
  • Open only what matches. Doing a git operation? The agent opens git-discipline.md and nothing else. Your memory can grow for years without bloating a single session.
  • 只打开命中的。 要做 git 操作？agent 只打开 git-discipline.md。记忆可以积累好几年，单次会话依然轻快。

04 / What you get你会得到什么

Everything is
a text file.

一切，
都是文本文件。

git-only

No server, ever

永远不需要服务器

No database, no daemon, no hosted API. Git already solves storage, history and conflicts — nestwork reuses it. Memory is plain files you can read anywhere.

没有数据库、没有常驻进程、没有托管 API。存储、历史、冲突 git 早就解决了，nestwork 直接复用。记忆就是普通文件，随处可读。

cross-tool

Six tools, one brain

六种工具，一个大脑

Installers for Claude Code, Codex CLI, Gemini CLI, Kimi Code, Hermes and OpenClaw, plus a generic installer for any markdown-configured agent.

为 Claude Code、Codex CLI、Gemini CLI、Kimi Code、Hermes、OpenClaw 提供安装脚本，任何用 markdown 配置的 agent 也能用通用脚本接入。

conflict-free

Built for many agents

为多 agent 而设计

Each agent owns agents/<host>/<id>/. Atomic per-write hooks pull, write, commit and push with retry — dozens of agents, no clobbering.

每个 agent 独占 agents/<host>/<id>/。逐次写入的原子 hook 自动 pull → 写 → commit → push 并重试，几十个 agent 同时写也不互相覆盖。

3.1

Topic memory

主题记忆

Skill-style routing: a generated index plus topic files. A --check guard fails on stale indexes, missing descriptions or oversized files.

skill 式路由：自动生成的索引 + 主题文件。--check 会拦住索引过期、缺描述或文件过大。

distill

Memory distillation

记忆蒸馏

Merge every agent's private notes into shared memory with claude -p or codex exec — a union, never destructive, human-reviewed.

用 claude -p 或 codex exec 把各 agent 的私有笔记合并进共享记忆——只做并集、从不删除、由人审核。

mailbox

Agent-to-agent mail

agent 之间能留言

One agent leaves a note in its outbox; another agent on another machine reads it when coordinating. No queue, no broker — just a file and a push.

一个 agent 往自己的发件箱写一条，另一台机器上的 agent 协作时就能读到。没有消息队列、没有中间件，就是一个文件加一次 push。

git-crypt

Optional encryption

可选加密

Turn on git-crypt and your git host only ever sees ciphertext, while agents keep reading and writing plain markdown.

开启 git-crypt 后，git 托管方看到的只有密文，agent 读写的依然是明文 markdown。

carryover

Rescue tool memory

把工具记忆救出来

Claude Code, Codex and Kimi each keep memory on one machine. Distill it into your nest so it survives a new laptop, a new tool or a lost account.

Claude Code、Codex、Kimi 的原生记忆都只存在单台机器上。把它们蒸馏进你的仓库，换电脑、换工具、丢账号都不怕。
